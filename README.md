# Flutter Firebase Auth + Riverpod App

Bu tətbiq Firebase Authentication, GoRouter naviqasiyası, Riverpod state idarəetməsi və Kamera/Qalereya inteqrasiyası ilə hazırlanmışdır.

## Paketlər (Dependencies)
- `firebase_core` & `firebase_auth`
- `flutter_riverpod`
- `go_router`
- `image_picker`

## Xüsusiyyətlər
- **Giriş və Qeydiyyat:** Email/Şifrə validasiyası ilə.
- **Sessiya Qorunması:** Yüklenərkən asinxron yoxlanış və avtomatik yönləndirmə.
- **Cihaz Funksiyası:** Qalereya/Kameradan profil şəkli seçilməsi və xəta idarəetməsi.
- **Çıxış (Logout):** Bir kliklə sessiyanın sonlandırılması.
